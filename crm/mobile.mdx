## Mobile Navigation

The mobile interface provides full access to CRM functionality with a touch-friendly interface optimized for smaller screens.

Mobile navigation uses a bottom tab bar for quick access to main sections. The interface adapts to different screen sizes and orientations, providing a consistent experience across devices.

## Mobile Features

Mobile-specific features include offline access, push notifications, and quick-add functionality for capturing leads on the go.

Mobile features include offline data access, push notifications for important updates, and quick-add forms for capturing new leads or contacts. The mobile app also includes GPS-based location services for field sales teams.
