## Overview

Importing existing data into Lynka CRM helps you get started quickly with your existing customer information. You can import leads, contacts, opportunities, and other data from various sources.

## Supported Formats

Lynka CRM supports importing data from:

- **CSV files**: Comma-separated values files
- **Excel spreadsheets**: .xlsx and .xls files
- **vCard files**: Contact information from other systems
- **API integration**: Programmatic data import

## Importing Leads

### Prepare Your Data

Before importing leads, ensure your data is properly formatted:

- Required fields: Name, Email (or Phone)
- Recommended fields: Company, Phone, Website, Address
- Optional fields: Job Title, Industry, Notes

### CSV Format

When importing from CSV, use the following column headers:

```csv
name,company,email,phone,website,address,job_title,industry,notes
John Doe,Acme Corp,john@example.com,555-1234,www.example.com,"123 Main St, Anytown",CEO,Technology,"Interested in premium plan"
```

### Import Process

<Steps>
<Step title="Prepare your file">
  Format your data according to the required structure and save as CSV or Excel file.
</Step>

<Step title="Navigate to import">
  Go to Settings > Data Management > Import and select the type of data you're importing.
</Step>

<Step title="Upload your file">
  Click "Choose File" and select your CSV or Excel file.
</Step>

<Step title="Map fields">
  Match the columns in your file to the corresponding fields in Lynka CRM.
</Step>

<Step title="Review and confirm">
  Preview the import to ensure data mapping is correct before proceeding.
</Step>

<Step title="Complete import">
  Start the import process and wait for completion. You'll receive a notification when finished.
</Step>
</Steps>

## Importing Other Data Types

### Opportunities

Import opportunities with fields like:
- Title
- Expected amount
- Probability
- Expected close date
- Associated lead
- Owner

### Products/Services

Import your product catalog with:
- Product name
- Description
- Price
- SKU
- Category
- Unit of measure

## Best Practices

<Tip>
  **Test with a small dataset first** to ensure your data mapping is correct before importing large datasets.
</Tip>

<Info>
  **Backup your data** before performing large imports to prevent accidental data loss.
</Info>

<Warning>
  **Duplicate detection** is enabled by default to prevent importing duplicate records.
</Warning>

## Troubleshooting

<AccordionGroup>
<Accordion icon="triangle-exclamation" title="Common Issues">
  <ul>
    <li>Incorrect file format - ensure CSV files use UTF-8 encoding</li>
    <li>Missing required fields - check that all mandatory fields are included</li>
    <li>Field mapping errors - verify column headers match expected format</li>
    <li>Large file size - split large files into smaller batches</li>
  </ul>
</Accordion>

<Accordion icon="clock" title="Import Times">
  Import times vary based on file size and complexity. Small files (under 100 records) typically import in seconds, while larger files may take several minutes. You can continue using the CRM while imports are processing.
</Accordion>

<Accordion icon="sync" title="Updating Existing Records">
  The import system can be configured to update existing records or only create new ones. Choose the appropriate option based on your needs.
</Accordion>
</AccordionGroup>

## Post-Import Actions

After successful import:

1. **Verify data accuracy** by checking a sample of imported records
2. **Clean up duplicates** if any slipped through the detection system
3. **Update pipeline stages** to match your business process
4. **Assign ownership** to team members if needed
5. **Set up automation** for newly imported records

<Note>
  For large data imports (over 10,000 records), consider contacting our support team for assistance with bulk import operations.
</Note>
