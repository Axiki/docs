Financial reports answer different questions about the same business. The fastest way to get confused is to force unlike reports to show the same number.

Use the report that matches the question you are asking.

## Operational reports and financial reports are not duplicates

A Sales report can show won Deal value. Agreements can show Invoice billings and A/R. Inventory can show stock value or product margin. Financial reports show the accounting view created from posted records and ledger rules.

The numbers should reconcile when they describe the same event and use the same scope, but they are not automatically identical measurements.

For example:

- won Deal value measures a commercial outcome
- Invoice total measures billing
- accounting revenue measures posted revenue
- A/R measures outstanding customer receivables
- cash measures cleared settlement and cash movement

Understanding those differences is more useful than making every dashboard card match.

## Where to start when something looks wrong

If the problem is structural, start with **Trial Balance**.

If one account is wrong, use **General Ledger**.

If performance looks wrong, use **Profit & Loss**.

If the financial position looks wrong, use **Balance Sheet**.

If collections are the problem, use **A/R Aging**.

If supplier obligations are the problem, use **A/P Aging**.

If bank balances do not agree, use **Bank Reconciliation Readiness** and the reconciliation workflow.

## Permissions

Financial reports can have permissions separate from ordinary Accounting access. A user who can create a supplier Bill does not automatically need permission to view every financial statement.
